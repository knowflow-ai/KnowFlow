⚡ 快速开始（5分钟部署）
================================================================================

第一步：加载 Docker 镜像
-----------------------
docker load -i rag-evaluation-latest.tar.gz

第二步：配置环境变量
-----------------------
编辑 .env.docker 文件，填入以下必填项：

    RAGFLOW_BASE_URL=http://ragflow:9380        # RAGFlow 服务地址
    RAGFLOW_API_KEY=ragflow-你的API密钥        # 从 RAGFlow 获取
    SILICONFLOW_API_KEY=sk-你的密钥            # 或其他 LLM API

第三步：启动服务
-----------------------
docker-compose up -d

第四步：访问系统
-----------------------
浏览器打开：http://localhost:5003

第五步：健康检查
-----------------------
curl http://localhost:5003/health

📋 系统要求
================================================================================

必须：
✅ Docker 20.10 或更高版本
✅ Docker Compose 2.0 或更高版本
✅ 2GB+ 可用内存
✅ RAGFlow 服务正在运行
✅ 至少一个 LLM API 密钥（硅基流动/OpenAI/DeepSeek）

推荐：
⭐ 4GB+ 内存
⭐ 2+ CPU 核心
⭐ 10GB+ 可用磁盘空间

================================================================================
🔧 常用命令
================================================================================

启动服务：
    docker-compose up -d

查看日志：
    docker-compose logs -f

停止服务：
    docker-compose down

重启服务：
    docker-compose restart

查看状态：
    docker-compose ps

进入容器：
    docker exec -it rag-evaluation bash

================================================================================
🌐 网络配置
================================================================================

默认配置：
- 端口：5003（可在 docker-compose.yml 中修改）
- 网络：连接到 RAGFlow 的 Docker 网络（ragflow_ragflow）

如果 RAGFlow 使用不同的网络名称：
1. 查看 RAGFlow 网络：docker network ls | grep ragflow
2. 修改 docker-compose.yml 中的 network 配置

================================================================================
📁 数据持久化
================================================================================

以下目录会自动创建并挂载到容器：

./data/     - 数据库文件
./logs/     - 系统日志
./tmp/      - 临时文件（数据集、评测报告等）

重要：定期备份 ./data 目录！

================================================================================
🔒 安全配置
================================================================================

生产环境部署时，请务必：

1. 修改 .env.docker 中的 SECRET_KEY 为随机字符串
2. 将 CORS_ORIGINS 改为具体域名，不使用通配符 *
3. 使用 HTTPS（通过 Nginx/Traefik 等反向代理）
4. 妥善保管 .env.docker 文件，不要上传到公开仓库
5. 定期备份数据目录

================================================================================
❓ 常见问题
================================================================================

Q1: 容器启动失败？
A1: 检查日志 docker-compose logs，确认环境变量配置正确

Q2: 无法连接到 RAGFlow？
A2: 确认 RAGFlow 正在运行，网络配置正确

Q3: 端口 5003 被占用？
A3: 修改 docker-compose.yml 中的端口映射，例如改为 "5004:80"

Q4: 前端页面打不开？
A4: 等待 30-40 秒让服务完全启动，检查容器健康状态

Q5: API 调用失败？
A5: 检查 LLM API 密钥是否正确，查看后端日志

更多问题请参考 QUICKSTART.md 的"常见问题"部分

📊 架构说明
================================================================================

本系统采用前后端一体化 Docker 容器部署：

┌─────────────────────────────┐
│   Nginx (端口 80)           │  ← 提供前端静态文件
│   ├─ 前端 Web 界面          │     反向代理后端 API
│   └─ API 反向代理           │
└─────────────┬───────────────┘
              │
┌─────────────▼───────────────┐
│   Flask Backend (端口 5002) │  ← 评测引擎
│   ├─ 数据集管理             │     报告生成
│   ├─ 任务调度               │     指标计算
│   └─ 报告生成               │
└─────────────┬───────────────┘
              │
┌─────────────▼───────────────┐
│   RAGFlow (端口 9380)       │  ← 被评测的 RAG 系统
└─────────────────────────────┘

🔄 版本更新
================================================================================

更新到新版本：

1. 停止当前服务：docker-compose down
2. 备份数据目录：tar czf data-backup.tar.gz data/
3. 加载新镜像：docker load -i rag-evaluation-new.tar.gz
4. 启动新版本：docker-compose up -d
5. 验证服务：curl http://localhost:5003/health

注意：重大版本更新前请仔细阅读更新说明！
