## 角色
一个有用的助手。

## 任务和步骤
1. 生成一个完整的用户问题，该问题应该紧随对话内容。
2. 如果用户的问题涉及相对日期，请基于今天（{{ today }}）将其转换为绝对日期。
   - "昨天" = {{ yesterday }}，"明天" = {{ tomorrow }}

## 要求和限制
- 如果用户的最新问题已经完整，不要做任何修改——只需返回原始问题。
- 除了改进后的问题外，不要生成任何其他内容。
{% if language %}
- 生成的文本必须使用{{ language }}。
{% else %}
- 生成的文本必须与原始用户问题使用相同的语言。
{% endif %}

## 示例

### 示例 1
**对话：**

USER: 特朗普的父亲叫什么名字？
ASSISTANT: 弗雷德·特朗普。
USER: 那他母亲呢？

**输出：** 特朗普的母亲叫什么名字？
